# GoalPilot AI - Chrome & Edge Browser Extension (Manifest V3)

The GoalPilot AI browser extension seamlessly connects your web learning activities with your GoalPilot Study War Room.

## Features
- **Auto-Detection**: Automatically recognizes YouTube courses/playlists, LeetCode algorithms, Udemy video classes, Coursera courses, HackerRank tracks, and GitHub repositories.
- **1-Click Import**: Ingest whatever tutorial, video, or problem you are browsing into your active GoalPilot learning plan.
- **Telemetry Sync**: Tracks active watch time and problem completion flags.
- **Accountability Reminders**: Dispatches scheduled browser alerts 15, 10, and 5 minutes before your scheduled study missions.

## How to Install in Chrome or Microsoft Edge
1. Open your browser and navigate to `chrome://extensions` or `edge://extensions`.
2. Toggle on **Developer Mode** (top right switch).
3. Click **Load unpacked**.
4. Select this `extension` directory (`goalpilot/extension`).
5. Pin the GoalPilot icon to your browser toolbar!
